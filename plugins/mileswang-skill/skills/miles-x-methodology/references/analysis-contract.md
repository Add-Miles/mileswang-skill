# Analysis Contract

## Evidence set

Create a short inventory of what was actually supplied and read:

- primary post text;
- author identity as presented by the source;
- quoted or parent posts;
- images and video content or transcripts;
- external documents;
- prior collected material from the same author.

For every missing item that could change the conclusion, say `未读取` and state
the effect. Do not silently omit it.

Comments are outside the default evidence set. If the user explicitly requests
comments, explain that this changes the analysis boundary and obtain clear
confirmation before incorporating them.

## Five-question separation

The five answers serve different purposes:

1. **Event or action:** observable sequence, decision, result, and stated cost.
2. **Problem:** the practical contradiction the source attempts to resolve.
3. **Principle:** causal explanation of why the action could create the result.
4. **Method:** repeatable sequence with inputs, decisions, feedback, and stop
   conditions; not a renamed principle.
5. **Transfer:** an action Miles can test in a real creator or business task.

Do not call a list of steps a first principle. Do not call a motivational claim
a method. Do not treat the proposed transfer as something the creator proved.

## Claim discipline

- Numbers need a source, metric definition, comparison baseline, and time range.
- Product or productivity claims need the actual input, intervention, output,
  and counterfactual before they can be treated as verified.
- An author statement is evidence that the author said it, not that it is true.
- Multiple posts can suggest a recurring pattern, but only supplied history can
  support that conclusion.
- Missing evidence lowers confidence; fluent language does not restore it.

## Minimum verification action

Use the same real input for a small A/B comparison whenever possible. Change one
main variable, define the observable result, cap time or cost, and state the stop
condition. If no useful comparison is possible, name the missing prerequisite
instead of inventing an experiment.
