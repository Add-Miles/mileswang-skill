# Report Template

Use only sections supported by the input. Keep labels next to the claims they
qualify.

## 结论先行

One direct conclusion. Mark it `事实摘要` or `AI 推断`.

## 已读取的材料

List read material and material that remains unavailable.

## 一、博主说了什么事

Reconstruct the actual event or action. Use `来源明确` and `事实摘要`.

## 二、博主回答了什么问题

State the practical problem. Mark interpretation as `AI 推断`.

## 三、第一性原理

State the causal chain and its hidden assumptions. Mark non-explicit reasoning
as `AI 推断`.

## 四、方法论

Describe a repeatable process, inputs, decisions, feedback, cost, and stop
condition. Separate the author's explicit method from the reconstructed method.

## 五、Miles 可以迁移什么

Give one creator-content action and one business action only when supported.
Mark both `Miles 可迁移行动`.

## 不能直接相信的部分

List `未核验主张`, missing baselines, unsupported generalization, and plausible
alternative explanations.

## 适用边界

State missing media, context, author history, or conditions that could change
the result. Explicitly say when a long-term author methodology cannot be judged.

## 最小验证动作

Define input, one changed variable, expected observable result, time or cost cap,
and failure stop condition. Mark it `Miles 可迁移行动`.
