# Content value gate

Separate two axes:

| Axis | Labels | Meaning |
| --- | --- | --- |
| Reading behavior | `glance` / `read` / `revisit` | How the user engaged the tab |
| Content value | `useful` / `filtered` | Whether the body enters a summary |

Never promote behavior into value. Never demote a tool post only because dwell was short.

## Pass (useful)

Must clear three questions:

1. Problem solved
2. How the user uses it
3. Method / tool / evidence / resource present

Examples: installable Skill with repo link; numbered workflow; checklist; concrete comparison with evidence.

## Fail (filtered)

- Authorization or “only for following accounts” notices
- Pure mood or chitchat
- Marketing with only capability claims
- Quote/repost with no added information

Do not rewrite filtered posts as knowledge essays.
